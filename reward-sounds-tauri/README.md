# Reward Sounds — UI на Tauri 2

Первый этап миграции интерфейса с egui на **Tauri 2 + HTML/CSS**. Рабочее
egui-приложение `../reward-sounds` не тронуто: этот каталог — отдельный
прототип нового UI-слоя.

## Стек

- **Rust + Tauri 2** — окно, команды, общий бэкенд `reward_sounds`.
- **HTML/CSS/JS без Node.js** — разметка и стили взяты из утверждённых
  макетов; ассеты встраиваются в EXE.
- **WebView2** — на Windows 10/11 уже установлен. Запускать нужно обычным
  двойным кликом, **не от имени администратора** (WebView2 не работает в
  процессе с высоким уровнем целостности).

## Что уже работает

- Окно 1220×840, кастомный titlebar: перетаскивание, свернуть,
  развернуть/восстановить, закрыть.
- Сайдбар, топбар, футер, переключение вкладок.
- **«Награды» — реальные данные Twitch**:
  - список наград канала через Helix API (токен читается из общего
    `config.toml`, при истечении обновляется по refresh token);
  - карточки по макету: цвет, цена, состояние, привязанный файл, формат
    и длительность, громкость;
  - поиск, фильтры («Все / Со звуком / Без звука / Играет / Выключенные»),
    сортировка, «Обновить»;
  - «Заменить»/«Выбрать звук» — системный диалог выбора файла, привязка
    сохраняется в конфиг;
  - «Убрать» — удаляет привязку;
  - ползунок громкости — сохраняет индивидуальную громкость и меняет её
    у играющих копий;
  - play — предпрослушивание через общий аудиодвижок;
  - «Остановить всё» — останавливает воспроизведение.
- **«Музыка» — реальный MusicService**:
  - очередь заявок с восстановлением после перезапуска;
  - плеер: play/pause, перемотка, «Сначала», «Пропустить трек»,
    прогресс и время в реальном времени;
  - громкость музыки сохраняется в конфиг;
  - ручная ссылка добавляет трек через yt-dlp;
  - убирание/поднятие заявок и очистка очереди;
  - строка «Сейчас играет» в OBS-оверлее (локальный сервер на 8770);
  - статус yt-dlp, платежная награда, счётчики очереди.
  Для работы рядом с EXE должен лежать `yt-dlp.exe` (в `dist/` и
  `F:\WorkSpaces\Mur rewards\reward-sounds-tauri\dist\` он уже есть).
- **Первый запуск** — две колонки и локальные привязки; показывается при
  отсутствии Twitch или через `?screen=onboarding&offline=1`.
- **«Настройки»** — реальные данные:
  - Twitch: Client ID, подключение/переподключение, отключение, экран
    ожидания кода активации (`twitch.tv/activate`);
  - звук: общая громкость, «Без звука», воспроизведение звуков наград;
  - приложение: автозапуск, закрытие в трей, запуск свёрнутым, версия;
  - музыка: статус готовности, выбранная награда и переход на вкладку.
- **«Журнал»** — реальный: читает `reward-sounds.log`, поиск, фильтры
  «Инфо / Предупреждения / Ошибки», обновление. Технические записи
  `get_state` скрываются, чтобы журнал был читаемым.
- **Создание/редактирование/удаление наград** — модальная форма (название,
  цена, цвет, ввод текста), кнопка «···» на карточке открывает редактирование.
- **EventSub** — приложение слушает активации наград, играет привязанные
  звуки в фоне, заявки музыки обрабатываются, статусы активаций обновляются.
- **Трей, single-instance, close-to-tray** — значок в трее с меню
  «Открыть / Выход», второй экземпляр не запускается, крестик прячет окно
  (если включено «Закрывать в трей»).
- Реальная громкость приложения читается из общих настроек и сохраняется
  командой `set_volume`.

## Запуск

```powershell
cd "F:\WorkSpaces\Mur rewards\reward-sounds-tauri\src-tauri"
cargo build --release
# обычный запуск, НЕ от администратора:
.\target\release\reward-sounds-tauri.exe
```

Готовый EXE: `F:\WorkSpaces\Mur rewards\reward-sounds-tauri\dist\Reward Sounds Tauri.exe`.

Dev-параметры: `?screen=rewards|music|onboarding|settings|log`,
`&offline=1`, `&obs=1`. Первый запуск также по `Ctrl+Shift+O`.

## Архитектура

- `src-tauri/src/core.rs` — состояние и команды: `get_state`,
  `refresh_rewards`, `choose_sound`, `clear_sound`, `set_sound_volume`,
  `preview_sound`, `stop_all_sounds`. Twitch-события забираются при
  запросах состояния; при первом запросе ждём загрузку наград.
- `src-tauri/ui/screens.js` — разметка экранов из макетов.
- `src-tauri/ui/app.js` — состояние, рендер реальных карточек, события.
- `src-tauri/build.rs` — хэширует `ui/`, чтобы Cargo пересобирал встроенные
  ассеты при изменении фронтенда.
