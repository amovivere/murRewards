## Часть 2. Сайдбар: точная причина и фикс

**Причина.** `.sidebar` — flex-колонка (`style.css:9`). Внутри три ребёнка: `.sidebar-main`, `.sidebar-system` и пустой `.sidebar-bottom`. Авто-маргина стоит **у двух**: `.sidebar-system { margin-top:auto }` (`screens.css:807`) и `.sidebar-bottom { margin-top:auto }` (`style.css:16`; сам элемент остался в `index.html:41`). Свободное место делится между двумя авто-маргинами примерно пополам → системная группа начинается чуть ниже середины, а вторую половину «съедает» невидимый пустой блок. Это ровно то, что видит пользователь.

**Фикс (рекомендация — оба действия):**
1. Убрать `<div class="sidebar-bottom"></div>` из `index.html` (в нём нет контента; версия уже в футере). Если правка HTML нежелательна — `.sidebar-bottom { display:none }`.
2. `.sidebar-main { flex: 1 1 auto; min-height: 0; }`, `.sidebar-system { margin-top: 0; }` — тогда main сам прижимает группу к низу, авто-маргинов не остаётся вовсе (устойчиво к добавлению элементов).
3. Полный сайдбар: над «СИСТЕМА» — разделитель по ширине (`border-top`, уже есть, `screens.css:829`), сверху отступ 10px, снизу — существующий `padding-bottom:16px`. Версию в сайдбар не добавлять.
4. Рейл 64px: `.sidebar-system { margin-top:auto }` остаётся **единственным** auto; текущий media-query убирает разделитель (`screens.css:830-832` `border-top:0`) — заменить на псевдоэлемент 32×1 по центру:
   `.sidebar-system::before { content:""; width:32px; height:1px; background:rgba(255,255,255,.09); margin:8px auto 6px; }`
   Лейблы скрыты (`.nav-label{display:none}`), у иконок уже есть `title` — добавить `aria-label` для скринридера, активное состояние — accent-soft.

**Приёмка:** в полном сайдбаре и в рейле верх «СИСТЕМА» отстоит от низа на высоту двух пунктов + отступ при любой высоте; в DOM ровно один `margin-top:auto`.

## Часть 3. Акцентный цвет

### 3.1 Где в UI

Карточка **«Внешний вид»** в «Настройках» — обычная карточка в `.settings-grid` (в 1220 — третья колонка после «Приложение»; в 980 — 2 колонки). Не делать full-width: это настройка, а не статус.

Содержимое (см. [макет](mockups/addendum-accent.png)):
- заголовок «Внешний вид» + sub «Акцентный цвет интерфейса. Не меняет цвет наград и статусы»;
- label «АКЦЕНТ»: образец 38×38 (native `input[type=color]`) + HEX-поле 110 + подпись «системный пикер — по клику на образец»;
- палитра **8 пресетов** 28px: `#8B00FF` (дефолт), `#6366F1`, `#3B82F6`, `#06B6D4`, `#14B8A6`, `#22C55E`, `#EC4899`, `#A3A3A3`; активный — кольцо цвета `--accent-text`; красный/янтарный/оранжевый **не включать** (совпадают со статусами warn/error);
- «Сбросить» (вернуть `#8B00FF`) + подпись «Применяется сразу · сохраняется автоматически»;
- scope-note: «Перекрашивается: активная вкладка, фокус, тумблеры/чекбоксы, ссылки, «играет», полоса плеера, приём заявок. Не перекрашивается: статусы, опасные действия, цвет наград, оверлеи OBS».

### 3.2 Токены и что перекрашивается

Ввести в `app.css` (загружается после `style.css`, до `screens.css`):
```css
:root {
  --accent: #8B00FF;           /* заливки: тумблеры, полосы, точки, активный фон */
  --accent-rgb: 139 0 255;     /* для rgba(var(--accent-rgb) / .14) */
  --accent-text: #C9A7FF;      /* мелкий текст/ссылки: mix(accent, white 45%) */
  --accent-soft: rgb(var(--accent-rgb) / .14);
  --accent-border: rgb(var(--accent-rgb) / .38);
  --ok: #22C55E;  --warn: #F59E0B;  --danger: #EF4444;  /* семантика — не акцент */
  --info: #7DD3FC;             /* уровень «ИНФО» в журнале — не акцент */
}
```
JS при старте/изменении: `document.documentElement.style.setProperty('--accent', hex)` + пересчёт `--accent-rgb`/`--accent-text` (микс 45% белого) и `--accent-soft/border`.

### 3.3 Контраст: пресеты и правило для произвольного цвета

Расчёт по WCAG (фон `#0A0A0A`; `text` — микс акцента с белым 45%):

| Пресет | fill/bg (≥3.0 для UI) | accent-text/bg (≥4.5) | белый текст на акценте |
|---|---|---|---|
| #8B00FF (дефолт) | 3.34 ✓ | 6.70 ✓ | 5.93 ✓ |
| #6366F1 | 4.43 ✓ | 9.29 ✓ | 4.47 ✗ (граница) |
| #3B82F6 | 5.38 ✓ | 10.04 ✓ | 3.68 ✗ |
| #06B6D4 | 8.15 ✓ | 11.92 ✓ | 2.43 ✗ |
| #14B8A6 | 7.95 ✓ | 11.88 ✓ | 2.49 ✗ |
| #22C55E | 8.69 ✓ | 12.35 ✓ | 2.28 ✗ |
| #EC4899 | 5.61 ✓ | 9.74 ✓ | 3.53 ✗ |
| #A3A3A3 | 7.85 ✓ | 12.33 ✓ | 2.52 ✗ |

Правила:
- **пресеты и произвольный цвет:** `contrast(accent, #0A0A0A) ≥ 3.0` (иначе — тост «слишком тёмный» и возврат к предыдущему) и `contrast(accent-text, #0A0A0A) ≥ 4.5` (при миксе 45% белого выполняется для всех пресетов — 6.7–13.8);
- ограничение HSL: `L 0.42…0.68`, `S ≥ 0.35` — за пределами снапить к ближайшему пресету с подсказкой «цвет осветлён/затемнён для читаемости»;
- **текст на акцентной заливке** (если где-то будет) — не фиксированный белый, а через `contrastTextColor(accent)` (#0A0A0A или #FFF) — как у цвета наград;
- серые/десатурированные цвета разрешать (они безопасны), чистый чёрный/белый — блокировать;
- в карточке «Внешний вид» показывать текущий контраст («3.34:1 · читаемо») рядом с HEX.

### 3.4 Поведение

- **Мгновенно**: input → `setProperty('--accent', …)` (без перезагрузки; CSS-переменные подхватываются сразу).
- **Сохранение**: debounce 300 мс → `set_app_setting({ key:'accent', value:hex })`; в Rust — поле `accent: String` в `Settings` + `CoreView.accent`, валидация hex и clamp по 3.3 (невалидный → `Err`→тост); `save()` как у остальных настроек.
- **Дефолт/сброс**: `#8B00FF`; «Сбросить» возвращает дефолт и сохраняет.
- **Без вспышки при старте**: продублировать акцент в `localStorage` и применять синхронно в `index.html`/`app.js` до первого опроса; авторитетное значение из `get_state` перетирает кэш.
- **980×680**: карточка в 2-колоночной сетке, превью-строка скрыта, палитра в 2 ряда; превью мини-UI не показывать (экономия высоты).
- **Рейл 64px**: ничего не добавлять; активная иконка уже accent-soft.
- **Оверлеи OBS**: акцент приложения **не** применять к стрим-оверлеям (у них своя тема/читаемость на видео); при желании — отдельная настройка «Акцент оверлея» позже.

### 3.5 Приёмка
- акцент меняется мгновенно во всех перечисленных группах и сохраняется между запусками; дефолт и «Сбросить» работают;
- статусы, опасные действия, белые CTA и цвета наград **не** меняются (тест на 8 пресетах);
- невалидный/нечитаемый цвет не применяется: тост + возврат предыдущего; контраст показан;
- нет вспышки фиолетового при старте с другим акцентом; на 980×680 карточка не ломает сетку.
