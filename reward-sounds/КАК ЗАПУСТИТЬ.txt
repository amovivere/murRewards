КАК ЗАПУСТИТЬ REWARD SOUNDS 1.7.0
================================

1. Распакуйте архив в любую папку, например: C:\RewardSounds
2. Откройте папку  dist
3. Дважды щёлкните файл  "Reward Sounds.exe"
4. Готово: откроется тёмное окно «Reward Sounds».

Если Windows покажет синее окно «Windows защитила ваш компьютер»:
   нажмите «Подробнее»  →  «Выполнить в любом случае».

ДЛЯ МУЗЫКИ (по желанию)
-----------------------
Положите yt-dlp.exe рядом с программой (в папку dist) или в папку tools.
Без него всё остальное работает, а на вкладке «Музыка» будет подсказка.

ПОДКЛЮЧЕНИЕ К TWITCH (один раз, ~5 минут)
-----------------------------------------
1. Включите 2FA на Twitch: twitch.tv/settings/security
2. Откройте https://dev.twitch.tv/console/apps → «Register Your Application».
3. Name: Reward Sounds (любое).
   OAuth Redirect URLs: http://localhost → Add (или https://localhost).
   Category: Application Integration.
   Client Type: Public (важно!).
4. Create → Manage → скопируйте «Client ID».
5. В программе: Настройки → «Подключение к Twitch» → вставьте Client ID →
   «Подключить Twitch».
6. Введите код из окна программы на twitch.tv/activate → Authorize.
7. В шапке появится «● Слушаем награды».

НАГРАДЫ И ЗВУКИ
---------------
1. Вкладка «Награды» — плитка или список, поиск и фильтры сверху.
2. «Выбрать звук» → выберите MP3 / WAV / OGG / FLAC.
3. ▶ — проверить (можно несколько раз — наложится).
4. «Заменить» / «Убрать» — поменять или отвязать звук.
5. «Остановить всё» — выключить все звуки.
6. Активируйте награду на канале — звук заиграет сам за 1–2 секунды.

УПРАВЛЕНИЕ НАГРАДАМИ
--------------------
1. «Создать награду» — название, цена, цвет → «Создать».
2. Меню «···» на карточке — изменить или удалить награду.
3. Обложку меняют только в панели Twitch (кнопка «Панель Twitch»).
4. Если Twitch не даёт управлять наградами — переподключите аккаунт:
   Настройки → Отключить Twitch → Подключить Twitch.

МУЗЫКА ПО ЗАЯВКЕ
----------------
1. На Twitch создайте награду с вводом текста (например, «МУЗЫКА ЮТУБ»).
2. Приложение → «Музыка» → выберите награду и цену → «Применить цену».
3. Включите «Принимать заявки», когда статус станет зелёным.
4. Зритель активирует награду и пишет ссылку на YouTube — трек встаёт в очередь.
5. Очередь: пауза, пропуск, перемотка, громкость, «убрать», «выше».
6. Ручная ссылка: поле «Вставьте ссылку YouTube» под очередью.

OBS-ОВЕРЛЕЙ «СЕЙЧАС ИГРАЕТ»
---------------------------
1. В OBS: источник «Браузер», ссылка http://127.0.0.1:8770/overlay
2. Ширина 1920, высота 200–300; «Обновлять при активации» выключить.
3. Приложение → «Музыка» → «Оверлей OBS» — шрифт, положение,
   «Показать сейчас».

ТРЕЙ, АВТОЗАПУСК, СВЁРНУТЫЙ ЗАПУСК
----------------------------------
* Крестик окна сворачивает программу в трей — она продолжает работать.
* Левый клик по иконке в трее открывает окно, правый — меню
  (открыть, включить/выключить звуки, остановить все, выход).
* «Завершить» внизу сайдбара — обычный выход из программы.
* Настройки → «Запуск и системный трей»:
  - «Запускать вместе с Windows» — автозапуск;
  - «При запуске показывать только иконку в трее» — старт без окна;
  - «Закрывать окно в трей» — включено по умолчанию.

ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
-----------------------
* Настройки → «Данные приложения» → «Открыть папку журнала» — там причина.
* Музыка: проверьте чек-лист на вкладке «Музыка» (Twitch, награда, yt-dlp).
* Ошибки в шапке/футере можно развернуть в журнале.
