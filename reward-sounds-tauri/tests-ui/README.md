# UI-тесты Reward Sounds (Tauri)

Смоук/интерактивные тесты реального окна через Chrome DevTools Protocol.
Тесты безопасны: не создают и не удаляют награды, не меняют цену музыки,
не трогают привязки звуков. Меняются только UI-настройки, которые тест
возвращает назад (например, «Без звука»).

## Что проверяется

1. Загрузка интерфейса и отсутствие ошибок в консоли.
2. Рендер всех вкладок: «Награды», «Музыка», «Настройки», «Журнал».
3. Переключатель «Плитка / Список».
4. Фильтр «Со звуком».
5. Модалка создания награды: открытие, автофокус, закрытие по Esc.
6. Редактор музыкальной награды сохраняет флаг «Нужен ввод текста».
7. Тумблер «Без звука» (включение и возврат).
8. Модалки «Награда и цена» и «Оверлей OBS».
9. Фильтр уровня и поиск в «Журнале».
10. Ошибка IPC показывается тостом, а не проглатывается.
11. Статус звука и версия в сайдбаре.
12. Разворачивание/восстановление окна.
13. Сохранение геометрии окна в `window.json`.

## Запуск

```powershell
# 1. Собрать exe
cd reward-sounds-tauri\src-tauri
cargo build --release

# 2. Закрыть запущенное приложение (иначе сработает single-instance)
# 3. Запустить тесты
cd ..\..
node tests-ui\run.mjs
```

Требуется Node.js 20+ (глобальные `fetch`/`WebSocket`). Скрипт сам поднимает
exe с `REWARD_SOUNDS_DEVTOOLS_PORT=9444`, ждёт CDP и после прогона закрывает
процесс. Переменные: `RS_TEST_EXE` — путь к exe, `RS_TEST_PORT` — порт CDP.

Если приложение не подключено к Twitch, тесты, зависящие от наград,
пропускаются, а базовые проверки вкладок всё равно выполняются.
