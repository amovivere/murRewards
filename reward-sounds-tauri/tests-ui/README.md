# UI-тесты Reward Sounds (Tauri)

Смоук/интерактивные тесты реального окна через Chrome DevTools Protocol.
Сейчас — **53 проверки**, все проходят (`53 passed, 0 failed`). Тесты безопасны:
не создают и не удаляют награды, не меняют цену музыки, не трогают привязки
звуков, не пишут сообщения в реальный чат. Меняются только UI-настройки,
которые тест возвращает назад (например, «Без звука»).

## Что проверяется

1. Загрузка интерфейса и отсутствие ошибок в консоли за весь прогон.
2. Рендер всех вкладок: «Награды», «Музыка», «Чат», «Настройки», «Журнал».
3. Переключатель «Плитка / Список», компактная плитка (4 колонки, карточка ≤150 px).
4. Фильтр «Со звуком»; меню карточки с «Заменить звук» / «Убрать звук».
5. Модалка создания награды: открытие, автофокус, закрытие по Esc.
6. Редактор музыкальной награды сохраняет флаг «Нужен ввод текста».
7. Тумблер «Без звука» (включение и возврат).
8. Модалки «Награда и цена», «Оверлей OBS», автосохранение настроек музыки
   (без кнопки «Сохранить»).
9. Фильтр уровня, поиск и «Отладка» в «Журнале».
10. Ошибка IPC показывается стеком тостов: русский текст, действие «Журнал»,
    интерфейс не падает.
11. Статус-хаб: чип состояния, поповер с 6 подсистемами, закрытие по Esc,
    версия в футере.
12. «Здоровье системы» и «Опасная зона» в настройках, единый «Тест звука».
13. Вкладка «Чат»: 4 карточки, 4 команды, поле ввода, ссылка `/chat`,
    статус в health; HTTP-страница и JSON `/chat/state` чат-оверлея.
14. Пустой плеер музыки с CTA «Поставить трек вручную».
15. Клавиатурное управление меню (стрелки, Esc).
16. Адаптив 980×680: рейл-сайдбар 64 px, список по умолчанию, громкость в
    списке, фильтры в поповере, тулбар в один ряд.
17. Разворачивание/восстановление окна, сохранение геометрии в `window.json`.

## Запуск

```powershell
# 1. Собрать exe
cd reward-sounds-tauri\src-tauri
cargo build --release

# 2. Закрыть запущенное приложение (иначе сработает single-instance)
# 3. Запустить тесты
cd ..\..
node tests-ui\run.mjs
```

Требуется Node.js 20+ (глобальные `fetch`/`WebSocket`). Скрипт сам поднимает
exe с `REWARD_SOUNDS_DEVTOOLS_PORT=9444`, ждёт CDP и после прогона закрывает
процесс. Переменные: `RS_TEST_EXE` — путь к exe, `RS_TEST_PORT` — порт CDP.

Если приложение не подключено к Twitch, тесты, зависящие от наград,
пропускаются, а базовые проверки вкладок и чата всё равно выполняются.
