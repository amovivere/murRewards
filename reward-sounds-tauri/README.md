# Reward Sounds — интерфейс на Tauri 2

Полноценный интерфейс приложения для стримера: награды Twitch Channel Points,
звуки, музыка по заявке из чата, OBS-оверлей чата с настройками, журнал
и настройки. Переписан с egui (`../reward-sounds`) на **Tauri 2 + HTML/CSS/JS**;
бэкенд общий — библиотека `reward-sounds`, поэтому поведение, конфиг и очередь
совместимы со старой версией.

## Стек

- **Rust + Tauri 2** — окно, команды, трей, single-instance, общий бэкенд.
- **HTML/CSS/JS без Node.js в рантайме** — ES-модули в `src-tauri/ui/`, ассеты
  встраиваются в EXE, внешних зависимостей нет.
- **WebView2** — на Windows 10/11 уже установлен. Запускать обычным двойным
  кликом, **не от администратора**.

## Структура UI

```
src-tauri/ui/
├── index.html          каркас: сайдбар, кастомный заголовок, шапка, футер
├── app.js              точка входа: навигация, опрос состояния, шапка, окно
├── js/bridge.js        мост к Tauri, состояние, тосты, модалки, меню, слайдеры
├── js/rewards.js       «Награды»: карточки/список, фильтры, редактор
├── js/music.js         «Музыка»: плеер, очередь, OBS, настройки музыки
├── js/sound-test.js    единый компонент «Проверить звук»
├── js/settings.js      «Настройки»: Twitch, звук, аудио, здоровье, данные
├── js/log.js           «Журнал»: уровни, поиск, отладка, автообновление
├── js/onboarding.js    первый запуск и локальные привязки
├── screens.css         стили компонентов, адаптив, доступность
├── app.css             дополнения к макету (hover, состояния, адаптив)
└── style.css           базовые стили макета (шрифт Inter встроен)
```

Tauri-команды описаны в `src-tauri/src/core.rs`; окно, трей, env-параметры,
сохранение и clamp геометрии под DPI — в `src-tauri/src/main.rs`. Чат-оверлей
(`/chat-overlay`) отдаёт `reward-sounds/src/music/overlay.rs`, страницы —
`reward-sounds/assets/chat-overlay*.html`, настройки сохраняются в
`%APPDATA%\RewardSounds\chat_overlay_settings.js`. Фоновый читатель `!трек` —
`reward-sounds/src/music/chat.rs`.
`build.rs` хэширует `ui/`, поэтому Cargo пересобирает встроенные ассеты при
изменении фронтенда.

## Что работает

См. корневой `README.md` — перечислены все функции. Кратко: награды и CRUD на
Twitch, привязки/громкости/прослушивание, EventSub-автовоспроизведение, музыка
(очередь, предзагрузка, плеер, возврат баллов, `!трек`), OBS-оверлей, настройки,
журнал, трей, первый запуск, сохранение геометрии окна. Заглушек и мёртвых
кнопок в интерфейсе нет: каждое действие вызывает реальную команду, ошибки
показываются стеком тостов и плашками, разрушительные действия подтверждаются.

Дополнительно в текущей итерации:

- **Статус-хаб в шапке**: один чип «Все системы работают» → поповер со статусами
  Twitch, EventSub, звука, yt-dlp и оверлея; проблемы ведут на нужный
  экран, есть «Здоровье системы» в настройках и «Скопировать диагностику».
- **Стек тостов**: ошибки не исчезают сами, у них есть действие «Журнал»,
  одинаковые сообщения схлопываются; английские ошибки ядра переводятся на
  русский. Выход из приложения — только через меню «···» с подтверждением.
- **Вкладка «Оверлей»**: полноценные настройки OBS-оверлея чата — пресеты,
  канал, темы Neon/Minimal, шрифты, цвета и прозрачности, TTL, анимации,
  хайлайты, эмодзи Twitch/BTTV/7TV, бейджи; живое превью и URL для OBS.
  Встроенного чата в приложении больше нет — только фоновый `!трек` для музыки.
- **Плотность**: компактные карточки по 4 в ряд (11 наград на экране),
  одинаковой высоты, индикатор «играет» вынесен на иконку и не сдвигает ряд;
  список с колонками, прослушиванием и сохранённой громкостью; на узких окнах
  — список по умолчанию, фильтры и сортировка в поповере «Фильтры».
- **Цвет награды** выбирается палитрой или системным пикером, HEX остаётся
  для точного значения; у недоступных кнопок плеера нет hover и курсора-кнопки.
- **Акцентный цвет интерфейса**: карточка «Внешний вид» в настройках — 8
  проверенных пресетов, системный пикер и HEX; применяется мгновенно ко всем
  акцентным элементам, сохраняется в `config.toml`, произвольный цвет мягко
  корректируется для контраста. Статусы, опасные действия и цвета наград не
  перекрашиваются.
- **Журнал** показывает новые записи сверху, очищается по подтверждению
  с архивом в `logs/archive-*.log`; системные вкладки («Настройки», «Журнал»)
  закреплены внизу сайдбара и в рейле 64 px.
- **Адаптив и DPI**: сайдбар-рейл 64 px до 1120 px, тулбар в один ряд, минимум
  900×620; стартовый размер окна подстраивается под рабочую область монитора,
  чтобы при 150 % DPI окно не выходило за экран.
- **Настройки/модалки**: Twitch с «Опасной зоной», единый «Тест звука»,
  настройки музыки с автосохранением (без кнопки «Сохранить»).
- **Доступность**: focus-visible на всех контролах, цели ≥32 px, меню
  управляются стрелками, перемотка — с клавиатуры, aria-label у иконочных кнопок.

## Запуск и dev-параметры

```powershell
cd reward-sounds-tauri\src-tauri
cargo build --release
.\target\release\reward-sounds-tauri.exe
```

- `REWARD_SOUNDS_DEVTOOLS_PORT=9333` — поднять CDP-порт WebView2 для отладки и
  UI-тестов. В обычном запуске порт закрыт.
- Данные: `%APPDATA%\RewardSounds` (`config.toml`, `queue.json`,
  `chat_overlay_settings.js`, `logs/`, `window.json`); переопределяется
  `REWARD_SOUNDS_DATA_DIR`.
- Рядом с exe нужен `yt-dlp.exe` (в `dist/` лежит). Без него работают награды
  и оверлей, а музыка показывает «yt-dlp не найден» с кнопкой повторного поиска.

## Тесты

- `cargo test --release` в `src-tauri` — 5 тестов Tauri-ядра.
- `cargo test --release` в `reward-sounds` — 97 юнит-тестов библиотеки
  (+ 5 интеграционных), включая оверлей.
- `node tests-ui/run.mjs` из `reward-sounds-tauri` — **62 проверки** реального
  окна через DevTools Protocol: вкладки, фильтры, модалки, оверлей,
  тосты, адаптив 980×680, журнал, ошибки IPC, окно, геометрия. Требуется
  Node.js 20+, приложение должно быть закрыто. Подробнее — `tests-ui/README.md`.

## Ограничения

- Установщик (NSIS/MSI) не собирается — используется portable exe + `yt-dlp.exe`.
- Глобальных горячих клавиш нет (как и в egui-версии).
- Чат: MVP — подключение/чтение/отправка, команды, оверлей. Модерация,
  автосообщения, свои команды и импорт из Nightbot/StreamElements — следующий
  этап (см. `.design/ux-review/2026-11-r2/next-iteration.md`).
- OBS-оверлей чата показывает последние сообщения; отдельная настройка
  шрифта/секунд есть в `chat.json`, но UI пока управляет темой и прозрачностью.
