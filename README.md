# Mur rewards — Reward Sounds

Приложение для стримера на Windows: играет локальные звуки при активации наград
Twitch Channel Points, ставит музыку по заявке из чата и показывает строку
«Сейчас играет» в OBS. Рабочая версия — **Tauri 2 + HTML/CSS/JS**; исходная
egui-версия осталась в `reward-sounds/` как бэкенд-библиотека и референс.

## Структура

- `reward-sounds/` — Rust-библиотека и старая egui-оболочка (бэкенд: Twitch,
  EventSub, аудио, музыка, очередь, оверлей, журнал, трей).
- `reward-sounds-tauri/` — новый интерфейс на Tauri 2 + HTML/CSS/JS поверх той
  же библиотеки:
  - `src-tauri/src/core.rs` — состояние и команды для UI;
  - `src-tauri/src/chat.rs` — чат канала (IRC, команды, настройки);
  - `src-tauri/src/main.rs` — окно, трей, single-instance, геометрия окна;
  - `src-tauri/ui/js/` — экраны (награды, музыка, чат, настройки, журнал, онбординг);
  - `src-tauri/ui/screens.css` — стили компонентов, адаптив, доступность;
  - `tests-ui/` — смоук/интерактивные тесты окна через DevTools Protocol.
- `reward-sounds-tauri/dist/Reward Sounds Tauri.exe` — собранный прототип;
  рядом должен лежать `yt-dlp.exe` (уже лежит).
- `.design/` — макеты, скрипты сравнения и отчёты этапа проектирования.
  Свежий UX-аудит и план итерации: `.design/ux-review/2026-11-r2/`.

## Что работает

- Вход в Twitch по коду, хранение и обновление токенов, отключение аккаунта.
- Награды: реальный список Channel Points, создание/изменение/удаление, цвет,
  цена, обязательный ввод текста; привязка/замена/удаление звука, прослушивание,
  индивидуальная громкость 0–200 %, поиск, 5 фильтров, сортировка, плитка/список,
  блок выключенных наград, привязки без награды, ошибки с «Повторить».
- Автовоспроизведение по EventSub (работает и в трее), общая громкость, mute,
  «Остановить всё», тестовый сигнал, перезапуск аудиовыхода, авто-выравнивание
  громкости всех привязанных звуков.
- Музыка: приём заявок из чата (`!трек` / `!track`), очередь с лимитами,
  предзагрузка, пауза/перемотка/пропуск, ручная ссылка, возврат баллов при
  отмене/ошибке, выбор награды и цены музыки, настройки очереди, пауза Яндекс
  Музыки, восстановление очереди после перезапуска.
- OBS: оверлей «Сейчас играет» на `127.0.0.1:8770/overlay`, настройка секунд,
  шрифта и положения, показ строки по кнопке и по команде из чата.
- Чат отдельной вкладкой: подключение к чату канала, чтение и отправка, команды
  `!queue`, `!song`, `!skip` (модератор), `!звук <название>`, кулдауны; живая
  лента сообщений; OBS-оверлей чата `/chat` с темой и прозрачностью. Старые
  токены без `chat:read/chat:edit` работают в режиме чтения и предлагают
  переподключить Twitch.
- Статус-хаб в шапке («Все системы работают») с поповером по Twitch, EventSub,
  чату, звуку, yt-dlp и оверлею; «Здоровье системы» в настройках и копирование
  диагностики; стек тостов с русскими ошибками и кнопкой «Журнал»; выход из
  приложения — только через меню «···» с подтверждением.
- Плотность и адаптив: 4 компактные карточки в ряд одинаковой высоты (11 наград
  на экране), список с колонками, прослушиванием и громкостью, рейл-сайдбар
  и один ряд тулбара на 980×680, минимум окна 900×620, стартовый размер под
  рабочую область монитора и DPI.
- Цвет награды — палитра + системный пикер; акцентный цвет интерфейса —
  карточка «Внешний вид» (8 пресетов, свой цвет, мгновенное применение и
  сохранение); журнал показывает новые записи сверху и очищается по
  подтверждению с архивом; системные вкладки закреплены внизу сайдбара.
- Настройки: Twitch с «Опасной зоной», единый компонент «Тест звука»,
  автосохранение настроек музыки; доступность — focus-visible, цели ≥32 px,
  клавиатурные меню и перемотка.
- Настройки: Twitch (вход/обновление данных/переподключение событий), звук,
  аудиовыход, приложение (автозапуск, трей, старт свёрнутым, выход), музыка,
  данные (пути, открытие папок). Индикатор «Сохранено».
- Журнал: уровни, поиск, «Показывать отладку», автообновление, открытие папки.
- Окно: кастомный заголовок (свернуть/развернуть/закрыть/перетаскивание),
  сохранение позиции и размера, трей с меню (открыть, звуки, стоп, выход),
  single-instance с показом существующего окна, «закрывать в трей» без
  перезапуска.
- Первый запуск: реальные шаги готовности и локальные привязки, которые можно
  слушать и настраивать даже без Twitch.

## Запуск

```powershell
cd "F:\WorkSpaces\Mur rewards\reward-sounds-tauri\src-tauri"
cargo build --release
# обычный запуск, не от администратора:
.\target\release\reward-sounds-tauri.exe
```

Или готовый файл:
`F:\WorkSpaces\Mur rewards\reward-sounds-tauri\dist\Reward Sounds Tauri.exe`

Настройки и токены Twitch хранятся в `%APPDATA%\RewardSounds`, поэтому после
переноса папки вход и привязки звуков сохраняются.

## Тесты

```powershell
# Rust: библиотека и Tauri-ядро
cd reward-sounds && cargo test --release
cd ..\reward-sounds-tauri\src-tauri && cargo test --release

# UI: реальное окно через DevTools Protocol (Node.js 20+, приложение закрыто)
cd "F:\WorkSpaces\Mur rewards\reward-sounds-tauri"
node tests-ui\run.mjs
```

UI-тесты поднимают exe с `REWARD_SOUNDS_DEVTOOLS_PORT` (порт CDP) и проверяют
загрузку, все вкладки (включая чат и чат-оверлей), фильтры, модалки, статус-хаб,
тосты, адаптив 980×680, журнал, ошибки IPC, окно и геометрию. Сейчас: 65 проверок.
Подробнее — `reward-sounds-tauri/tests-ui/README.md`.

## Git

Репозиторий инициализирован в корне проекта (ветка `main`). В коммиты попадают
исходники обоих приложений, документация, скриншоты и материалы дизайна
(`.design/`). Артефакты сборки не хранятся в репозитории: `target/`, `dist/`
(включая `Reward Sounds Tauri.exe` и `yt-dlp.exe`), `*.exe`, логи, кэши Python
и сгенерированные схемы Tauri — см. `.gitignore`.

После клонирования готовые exe нужно собрать заново (см. «Запуск»), а
`yt-dlp.exe` положить в `reward-sounds-tauri/dist/` вручную.

```powershell
git status
git log --oneline
```
