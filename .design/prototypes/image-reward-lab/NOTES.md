# NOTES — комбинированные карточки «звук + картинка»

Расширение концепта «картинка на экране за баллы»: одна награда Channel Points может содержать
**звук**, **набор картинок** или **и то, и другое**. Код приложения не менялся; всё в
`.design/prototypes/image-reward-lab/`.

## 1. Сценарий и режимы

Карточка хранит `mode: sound | image | both`:

- **sound** — как звуковые награды сейчас: при активации играет привязанный звук (из приложения).
- **image** — в OBS-оверлее появляется случайная картинка из набора, в случайной точке, под углом до ±40°.
- **both** — одновременно: приложение играет звук, OBS показывает картинку. Один звук на карточку
  (существующее поведение), картинок — до 8, выбирается случайная.
- **одной части нет** (both без картинок или без звука) — срабатывает только имеющаяся часть;
  карточка показывает warning-чип и подсказку, что именно произойдёт.
- **обеих частей нет** — пустая карточка: активация игнорируется, баллы возвращаются, в журнале
  «активация без содержимого».

В настройках режим переключается без потери данных другой части: звук и картинки остаются в конфиге.

## 2. Карточка в списке

- **A · Media-first**: веер «полароидов» (до 3 + счётчик), звуковая плашка в чипах (`♪ файл · 100%`),
  чипы режима/картинок/угла/длительности, кнопки «Показать» и «Настроить».
- **B · Compact**: стек 38 px (или иконка звука), чипы-режим + звук + картинки; «Редактор»/«Показать».
- Три состояния и частичные случаи явно различаются бейджами и warning-чипами; высота карточек
  фиксирована (A ~328 px, B ~176 px), сетка не «пляшет».
- Обложка: первая картинка помечается звёздочкой и ставится первой в веере/стопке.
- В списке карточки сжимаются в строку: стек/иконка звука, название, режим, чипы, действия.

**Рекомендация:** карточки A для экрана «Награды» + редактор B как модалка (гибрид). При 20+ наградах
переключатель «Плитка/Список» закрывает плотный режим.

## 3. Настройки комбинированной карточки

Сверху — сегмент **«Звук / Картинки / Звук + картинки»** с пояснением. Дальше — только относящиеся секции:

### Звук (если mode ≠ image)

- текущий файл: имя, формат/длительность, статус;
- **Прослушать** (в прототипе — синтезированный пример), **Заменить**, **Убрать**;
- громкость 0–200% (как у звуковых наград), независимо от громкости Windows;
- если звука нет — «Звук не выбран» + «Выбрать звук», подсказка «сработает без звука — только картинки».

### Картинки (если mode ≠ sound)

- 0–8 картинок, добавить/удалить, счётчик, «сделать обложкой» (звёздочка);
- пустой набор — предупреждение и вариант «сработает только звук» (для both);
- превью-появление и настройки: максимальный угол 0–40°, размер 12–60%, длительность 1–10 с,
  прозрачность 50–100%, safe area 0–15%, позиция «случайно / центр».

### Превью

16:9 сцена OBS: кнопка «Показать» запускает **звук и анимацию картинки одновременно**; readout
`x · y · угол`, чип `звук · файл · громкость`, прогресс времени. Если картинок нет — превью
показывает только звук (большой эквалайзер), если звука нет — только картинку.

### Опционально (v1.1, свёрнуто и disabled)

задержка после активации, зоны (углы/края/центр), «без повторов подряд», отдельный звук появления,
GIF/видео, лимит показов на стрим.

## 4. Активация: что происходит

```
если mode != image и sound != null      → играть звук (громкость карточки)
если mode != sound и media не пусто     → выбрать случайную картинку
                                          выбрать x,y (safe area, размещение)
                                          выбрать угол ±max_angle
                                          отправить в OBS-оверлей событие показа
если нет ни звука, ни картинок          → отменить redemption, вернуть баллы, записать в журнал
```

- Звук играет приложение (как сейчас) — его **не дублирует** OBS-оверлей.
- OBS-оверлей отвечает только за картинку: прозрачный Browser Source, анимация по событию.
- Если одна часть недоступна — играет/показывается доступная, в журнале пометка «только звук» /
  «только картинка», чтобы стример понимал неполное срабатывание.
- Random выбирается сервером один раз: единый источник правды для журнала, повторяемости и OBS.

## 5. Data model (конфиг карточки)

```jsonc
{
  "reward_id": "twitch-reward-uuid",
  "mode": "both",                         // sound | image | both
  "enabled": true,
  "sound": {                              // существующее поле звуковой награды
    "file": "newbie.mp3",
    "volume": 100,                        // 0..200, %
    "duration_ms": 900
  },
  "media": [
    { "id": "m_01", "file": "cat.png", "thumb": "cat_320.webp",
      "mime": "image/png", "width": 1024, "height": 1024, "bytes": 480123,
      "sha256": "…", "added_at": "2026-11-19T12:00:00Z" }
  ],
  "cover_id": "m_01",                     // обложка (первая в веере/списке)
  "image": {
    "max_angle_deg": 40,                  // 0..40
    "size_pct": 32,                       // 12..60, ширина экрана
    "opacity": 0.95,
    "duration_ms": 4000,
    "safe_margin_pct": 6,
    "placement": "random"                 // random | center (v1.1: zones)
  },
  "trigger": { "on_redemption": true, "delay_ms": 0 },
  "limits": { "max_images": 8, "max_bytes": 8388608, "max_dim": 2048 }
}
```

- `mode` и `sound` можно мигрировать из текущих звуковых наград: старые награды → `mode: "sound"`.
- Награда без картинок и без звука хранится как `mode: "both"`, `media: []`, `sound: null` —
  UI показывает «пустая карточка», активация не срабатывает.

## 6. Backend contract

### Хранение

- картинки: `%APPDATA%/RewardSounds/image-rewards/<reward_id>/<uuid>.<ext>` + `thumbs/`;
- PNG/JPEG/WebP (MVP), до 8 файлов на карточку, 8 МБ/файл, 2048 px по длинной стороне;
- звук — существующее хранилище звуков наград (1 файл на карточку);
- проверка magic bytes, размеров; перекодирование при превышении.

### Команды

```text
image_reward_get(reward_id) -> Card
image_reward_add_media(reward_id, paths[]) -> Card
image_reward_remove_media(reward_id, media_id) -> Card
image_reward_set_cover(reward_id, media_id) -> Card
image_reward_set_settings(reward_id, patch) -> Card     // mode, angle, size, duration, opacity, safe, placement
image_reward_preview(reward_id) -> ()                   // ручной показ: звук + картинка, без баллов
image_reward_open_folder(reward_id) -> ()
reward_set_sound(reward_id, path) / reward_set_sound_volume(reward_id, volume)  // существующие/новые
reward_set_mode(reward_id, mode) -> Card
```

### Поток активации (Twitch redemption)

```text
ActivateReward(reward_id, user):
  cfg = image_rewards.get(reward_id)
  sound = cfg.mode != image ? cfg.sound : null
  media = cfg.mode != sound && cfg.media.not_empty ? cfg.media : []
  if !sound && media.empty:
      cancel redemption (refund), journal "нет содержимого"
      emit RewardActivation {result:"empty"}
      stop
  if sound: play_sound(cfg.sound.file, cfg.sound.volume)   // приложение
  if media:
      item = uniform_random(media)
      angle = uniform(-max_angle, +max_angle)
      (x,y) = random_point(safe_margin, size_pct, placement)  // 1920×1080
      emit ImageRewardShown {
        reward_id, mode, media_id, url, x, y, angle,
        size_pct, opacity, duration_ms, user, ts
      }
  journal "Активация: звук + картинка" / "только звук" / "только картинка"
```

### OBS-оверлей

- новый Browser Source: `http://127.0.0.1:8770/image-reward` (1920×1080, прозрачный);
- `GET /image-reward/state` — последний показ картинки (polling 400–500 мс) или SSE `/image-reward/events`;
- `GET /image-reward/media/<media_id>` — immutable, только из своей папки;
- оверлей проигрывает вспышку/появление/hold/исчезновение по полям события.
- Звук в OBS — **не** через этот оверлей: играет приложение в аудиоустройство стрима,
  как существующие звуковые награды. Это важно не задвоить.

### Журнал

- `Картинка: @user · <media name> · x 41% y 63% · +23° · 4 с` (если есть картинка);
- `Активация: звук <file> · 100%` / `Активация: только звук` / `Активация: только картинка`;
- `Пустая карточка — баллы возвращены`.

## 7. Приоритеты и что внедрять первым

**P0 (MVP)**
1. Поле `mode` + `sound` + `media[]` в конфиге; миграция старых звуковых наград в `mode:"sound"`.
2. Активация: звук (существующий путь) и/или случайная картинка; пустая карточка → refund.
3. OBS-оверлей `image-reward` с событием и анимацией; случайные x/y/angle на сервере.
4. Настройки: режим, звук (выбрать/прослушать/громкость), картинки (0–8, добавить/удалить/обложка),
   угол/размер/длительность/прозрачность/safe area, предпросмотр.
5. Лимиты файлов и валидация, журнал активаций.

**P1**
6. Частичные случаи: явные предупреждения + журнал «только звук/картинка».
7. «Без повторов подряд», задержка, зоны, лимит показов на стрим.
8. Ручной показ из карточки/списка, быстрые действия в списке.
9. Пресеты оформления (рамка/тень) и настройка звука появления.

**P2**
10. GIF/видео, вес картинок, очередь активаций, аналитика показов, несколько картинок на звук-триггеры.

**Рекомендация по внедрению:** сначала P0-вертикаль «конфиг карточки → активация → звук+картинка →
OBS-оверлей → журнал» на одном типе награды; затем UI-редактор с переключателем режима и обложкой;
после первых тестов — «без повторов подряд» и зоны, затем лимиты/аналитика. Визуально — карточки A
на экране наград + редактор B.
