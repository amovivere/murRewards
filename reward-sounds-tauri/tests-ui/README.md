# UI-тесты Reward Sounds (React + Tauri)

Смоук-тесты реального окна через Chrome DevTools Protocol.
Сейчас — **43 проверки**, все проходят (`43 passed, 0 failed`). Тесты безопасны:
не создают и не удаляют награды, не меняют настройки, не очищают журнал.

## Что проверяется

- React-интерфейс загружается, ошибок в консоли нет.
- Есть вкладки «Награды, Музыка, Оверлей, Настройки, Журнал»; вкладки «Чат»
  и служебных прототипных страниц нет.
- Окно не меньше 1600×1000.
- Награды: количество карточек совпадает с `get_state`.
- Музыка: экран открывается, состояние берётся из бэкенда, в плеере есть
  громкость и кнопки не меньше 40 px.
- Оверлей: экран открывается, превью указывает на реальный
  `127.0.0.1:8770/chat-overlay`.
- Настройки: health-строки приходят из бэкенда.
- Журнал: записи загружаются.
- Модалка «Новая награда» открывается и закрывается.
- Нет ошибок в консоли за весь прогон.

## Запуск

```powershell
# 1. Собрать exe
cd reward-sounds-tauri\src-tauri
cargo build --release

# 2. Закрыть запущенное приложение (single-instance)
# 3. Запустить тесты
cd ..\..
node tests-ui\run.mjs
```

Требуется Node.js 20+ (глобальные `fetch`/`WebSocket`). Скрипт сам поднимает
exe с `REWARD_SOUNDS_DEVTOOLS_PORT=9444`, ждёт CDP и после прогона закрывает
процесс. Переменные: `RS_TEST_EXE` — путь к exe, `RS_TEST_PORT` — порт CDP.

Старые vanilla-тесты (62 проверки) сохранены в `legacy-run.mjs` и относятся
к архивному интерфейсу в `src-tauri/ui/legacy/`; основной прогон их не запускает.
