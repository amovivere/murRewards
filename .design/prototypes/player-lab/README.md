## Что внутри

- `src/App.jsx` — вся логика плеера, очереди, модерации и двух раскладок.
- `src/styles.css` — дизайн-токены приложения + стили A/B.
- `shots/player-A.png`, `shots/player-B.png` — скриншоты 1440×1080.
- `scripts/interaction-check.mjs` — headless-проверка (Edge + CDP) 13 сценариев: play/pause, «Следующий», «Пропустить» с возвратом баллов и undo, seek, громкость, добавление ссылки, A/B, Space. Запуск: `node scripts/interaction-check.mjs` (нужен запущенный dev-сервер на 5175).
- `NOTES.md` — семантика кнопок, список функций с приоритетами и рекомендации по внедрению.

## Варианты

**A · Stage** — сцена для стримера: крупная обложка-винил, большой текущий трек, крупные цели управления, очередь справа, журнал/статистика/OBS снизу.

**B · Console** — пульт модератора: компактная строка плеера сверху, очередь как таблица заявок с действиями, карточка «Правила и модерация» с разницей «Следующий / Пропустить», блок-лист, журнал, OBS и хоткеи.

## Управление в конструкторе

| Действие | Как |
|---|---|
| Play / Pause | кнопка в транспорте, `Space` |
| Следующий трек | кнопка «Следующий трек», `Shift + →` |
| Пропустить заявку | «Пропустить…» → причина → возврат баллов, `S` |
| Перемотка | клик/драг по полосе, `←` / `→` |
| Громкость | слайдер, `↑` / `↓`, mute — `M` |
| Очередь | ▶ включить сейчас, ↑↓ порядок, × убрать с возвратом баллов, ссылка в поле внизу |
| A/B | сегмент в шапке или `V` (вариант пишется в URL) |

Всё управление — на фейковых данных: очередь, загрузка/ошибка, возврат баллов, журнал, оверлей и статистика эмулируются в памяти.
